<h1>Whats BetterMSG?</h1>
BetterMSG is a optimized and lightweight alternative to EssentialsX integrated MSG-System. There are no limits from changing the permissions to let the plugin look like yours!

<h1>Version Support</h1>
The Plugin should work fine with Versions from 1.13 to the currently newest release 1.21.8 on SpigotMC (& Forks)
