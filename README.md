> Transform your server's chat with color codes, custom prefixes, and granular permission control — all in one lightweight plugin.

---

## ⚡ Features

### 🎨 Color Codes in Messages
Players can use Minecraft's standard color codes (`&a`, `&b`, `&c`, ...) directly in chat — making conversations more vibrant and expressive than ever.

### 🏷️ Custom Prefixes
Give players or groups unique prefixes to reflect their role on the server. Configure them via in-game commands or the config file — no restart needed.

### 🔐 Permission Management
Fine-grained control over who can use what:
- Restrict color codes to specific ranks
- Enable or disable messaging features per player
- Keep your chat clean and abuse-free

### 📜 User-Friendly Commands
Simple, intuitive commands to manage everything on the fly. Reload the config without restarting your server — changes apply instantly.

---

## 🛠️ Installation

1. Download the `.jar` file
2. Drop it into your server's `/plugins` folder
3. Restart your server
4. Customize via `/plugins/BetterMSG/config.yml`
5. Done! ✅
